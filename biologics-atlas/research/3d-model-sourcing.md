# Full-body human skeleton 3D model: sourcing report

Date: 2026-10-22. Purpose: a skeleton that can be rendered in three.js on jaybeatty.com (public, non-commercial educational reference page, attribution shown), with bones as separate named meshes so regions can be colored and picked.

Every license line below was read at the source on 2026-10-22, and every download URL was hit with curl (HEAD or range request) without a login. Sizes are the server-reported `Content-Length` unless marked "observed" (file on disk).

## Recommendation in one paragraph

Use **Écorché** (`Charleeh/ecorche` on GitHub): a 13.7 MB glTF binary, CC BY-SA 4.0, 634 named meshes of which 272 form a `Skeleton` node (198 bones, 42 cartilages, 28 teeth, 4 eye parts), each node carrying `extras` with the anatomical name, side, tissue and FMA id. It is built from BodyParts3D plus Z-Anatomy and is the only candidate found that is glTF, structured per bone, named, and under 30 MB. Strip the two muscle layers at build time and the skeleton alone is about 255k triangles (roughly a quarter of the file). The obligations are attribution (a one-line credit, text below) and share-alike on any modified mesh we publish; the page itself is not a derivative, only a decimated or re-exported mesh would be. The main caveat is provenance: the repository is two weeks old (created 2026-10-07, one commit, one star, pseudonymous owner), so keep our local copy and keep the fallback (BodyExplorer's `skeleton.glb`, pure BodyParts3D, 201 named bones, 9.8 MB) in reserve.

### Checked and ruled out

- **Smithsonian Open Access (3d.si.edu)**: the site returns HTTP 403 to non-browser clients; the Human Origins 3D page states hominin fossil models are not downloadable and primate skeletons are non-commercial only. No CC0 human skeleton was found by search. Not usable here.
- **three.js `examples/models`**: the gltf folder (listed through the GitHub API) has no skeleton; the other format folders are demo assets (ferrari, soldier, horse, etc.).
- **GitHub search**: `olivercase/body_parts_3d_api` hosts all 3,210 full-resolution BodyParts3D 4.3 OBJ meshes via Git LFS (data "CC-BY-SA 2.1 Japan" per its README, code MIT); useful if we ever want full-resolution bones, but it is the raw dataset, not a ready skeleton. `vincentgg6886/3D-Human-Skeleton` is MIT code with no model file in the repo (290 KB).
- **Open Anatomy Project / SPL atlases**: nothing found with a direct skeleton download; the SPL atlases are brain/abdomen/knee, not a whole skeleton.
- **Sketchfab, CGTrader, TurboSquid**: skipped per the brief (account-walled downloads).
- **NIH 3D 3DPX-016666** (female thigh/knee/leg bones, Visible Human): CC-BY-NC-SA, partial, not needed.

## License notes that matter

1. **BodyParts3D has two license statements in the wild.** The current DBCLS license page (updated 2025/02/27) says CC BY 4.0 and gives the credit line "BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International". The OBJ file headers in the 4.0 archive, the Wikimedia Commons uploads (2014), Z-Anatomy, BodyExplorer and anatomi-simulatoru all say CC BY-SA 2.1 Japan. Safest course: show both the current CC BY 4.0 line and the CC BY-SA 2.1 JP line, and treat any mesh we modify as share-alike anyway.
2. **Z-Anatomy is CC BY-SA 4.0**, and it forbids relicensing derivatives ("You must distribute any derivative work ... under the same license"). Any model that includes Z-Anatomy geometry (Écorché's muscles and a few face/jaw parts; all of anatomi-simulatoru's files) is therefore share-alike. Écorché's **skeleton layer is entirely BodyParts3D-sourced** (all 272 skeleton entries have `source: "BodyParts3D"` and an FMA id), but Écorché licenses the whole model file as CC BY-SA 4.0, so we honour CC BY-SA 4.0 for it.
3. **What share-alike means for us**: attribution on the page; if we publish a decimated or re-exported GLB (we will), that file must carry a CC BY-SA 4.0 notice and the credit line. The HTML/JS of the page is not a derivative of the mesh.
4. Nothing in the top three requires a login, a form, or acceptance of terms; all are plain HTTPS GETs from GitHub.

## Recommendation and tradeoffs

**Primary: Écorché `ecorche.glb`** (or `ecorche.meshopt.glb` for the web).

- Structure quality: best available. Per-bone nodes with proper names, side, tissue and FMA ids in `userData`, grouped under a `Skeleton` node, so region colouring is a lookup table keyed on name/FMA (we need to build the region map ourselves: e.g. the skull is 14 or so cranial/facial nodes, the pelvis is left/right hip bone plus sacrum; the sternum is three nodes: "Manubrium", "Body of sternum", "Xiphoid process"; a name check found no coccyx and no hyoid node, so the atlas should not promise those).
- Page weight: 13.7 MB as shipped (5.7 MB meshopt, 4.2 MB gzipped per the README). Dropping the 362 muscle meshes leaves ~255k triangles for the skeleton, which should land around 3 to 4 MB quantized or 1.5 to 2 MB meshopt before any decimation; after a 50 % decimation it should be comfortably under 2 MB.
- Loader needs: `KHR_mesh_quantization` is handled natively by three.js GLTFLoader; the meshopt file additionally needs `GLTFLoader.setMeshoptDecoder(MeshoptDecoder)` (both ship with three.js examples/jsm). The root node has scale 0.0001; keep it or apply it when re-exporting. Colours are vertex colours on two white materials; switch `vertexColors` off to colour by region.
- License obligations: show the credit line; publish any modified GLB under CC BY-SA 4.0 with the credit. Share-alike is acceptable per the brief.
- Risk: new, single-author repository (created 2026-10-07, one commit, one star, GitHub Pages demo live at https://charleeh.github.io/ecorche/). The license text is unambiguous and the pipeline in `tools/` claims byte-identical rebuilds from the original downloads, which is good for provenance, but the repo could disappear; we hold a local copy and the upstream data is public.

**Fallback A: BodyExplorer `skeleton.glb`** (pure BodyParts3D, 201 named bones, 9.4 MB, ~500k triangles). Same bone naming scheme as Écorché minus cartilage and teeth, no `extras`, lowercase names, no sacrum found by name. License is the BodyParts3D license only (CC BY 4.0 now, CC BY-SA 2.1 JP historically), so arguably lighter obligations than Écorché, at the cost of a less tidy file and a less explicit license statement from the redistributor.

**Fallback B: anatomi-simulatoru `iskelet.glb`** (Z-Anatomy export, 5.0 MB, 233 meshes, ossicles and sternum parts present). Z-Anatomy's naming with `.l/.r` suffixes and TA2-aligned names is nice, but the mirrored nodes (negative scale) need care in three.js (front-face winding flips) and the file is CC BY-SA 4.0 outright.

**If a single untextured silhouette is ever enough**: NIH 3D 3DPX-016838 (CC BY 4.0, one fused mesh, 9.6 to 44.8 MB) or the CC0 Quaternius low-poly skeleton on Poly Pizza (0.3 to 0.7 MB).
